This is a chore tracking/chore automation app.

It is useful to set/send periodic reminders about stuff to do (laundry, hoover, etc.). It also supports "remind me in x" or "remind me to do x before y"
It communicates daily with the user through a telegram bot (so it is a telegram bot).
chores/items to do can have owners (that are part of a telegram chat with the bot). 

We can also automate some stuff, keep track of arbitrary lists of items (like what groceries we should buy, etc.)
It is agent-first, so it has a MCP server so that agents can also use it. It also has a nice and cozy web ui.

Implement it in rust.
